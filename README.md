# Low-Area-ALU
This is a A low-area multi-operation ALU implemented using shared Datapath architecture with reusable hardware blocks. Includes verification using Systemverilog synthesis, logic equivalence checking, and basic physical design using Cadence tools. Performed a transaction-based SystemVerilog verification environment using OOP concepts (driver, monitor, scoreboard) with randomized stimulus and reference model for self-checking functional validation Achieved 9.3\% area reduction and 11.1\% total power reduction compared to baseline design
